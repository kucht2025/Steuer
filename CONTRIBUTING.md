# Beitrag zu Beleg Assistent Lohnsteuer

Vielen Dank für dein Interesse, an diesem Projekt mitzuwirken. Bitte beachte folgende Hinweise für Pull Requests:

1. Erstelle ein Issue, bevor du mit der Arbeit beginnst.
2. Forke das Repository und erstelle einen neuen Branch für deine Änderungen.
3. Achte auf einen verständlichen Commit-Verlauf und beschreibe deine Änderungen.
4. Lasse `flake8` und ggf. vorhandene Tests laufen, bevor du einen Pull Request erstellst.
5. Beschreibe im PR kurz Motivation und Lösung.

Bitte halte dich an einen respektvollen Umgangston. Wir orientieren uns an der [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/).
